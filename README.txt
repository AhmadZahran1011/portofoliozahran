Penjelasan Singkat Website

https://zahran.ifportofolio.com/ (Link sub domain)

Website ini merupakan sebuah halaman informasi sederhana yang dirancang untuk menampilkan konten dengan tampilan modern dan bersih. Menggunakan latar belakang gradient biru-ocean, website ini memberikan kesan profesional dan menyegarkan. Struktur tata letak dibangun menggunakan elemen-elemen HTML dasar seperti header, section, card, dan footer, sehingga mudah dipahami, dikelola, dan dikembangkan.

Navigasi utama ditempatkan di bagian paling atas menggunakan navbar, yang memungkinkan pengguna berpindah halaman dengan mudah. Bagian konten utama berisi sebuah card berdesain elegan yang menampilkan informasi inti dari website, seperti judul utama, deskripsi, dan tombol aksi. Komponen card ini memanfaatkan kombinasi Bootstrap utilities dan custom CSS agar tampil responsif di berbagai ukuran layar. Di bagian bawah, terdapat footer sederhana yang menutup halaman dengan rapi, memberikan kesan profesional pada keseluruhan desain.

Penjelasan Komponen-Komponen HTML yang Digunakan
Berikut penjelasan setiap komponen penting yang digunakan:

1.Navigation Bar
Digunakan untuk membuat area navigasi di bagian atas website. Biasanya berisi:
Logo atau tulisan brand
Link navigasi seperti Home, About, Contact
Dengan Bootstrap, navbar menjadi responsif secara otomatis.

2.Container
Container berfungsi mengatur tata letak agar konten tidak terlalu mepet di pinggir layar. Ini adalah komponen umum dalam Bootstrap.

3.Card Component
Komponen utama yang digunakan untuk menampilkan informasi dalam bentuk kotak yang rapi. Didalamnya terdapat:
<div class="card-body"> → area isi card
<h5> → judul card
<p> → paragraf penjelasan
<button> / <a> → tombol aksi
Card memberikan tampilan modern, bersih, dan fokus pada konten.

4.Content Section
Digunakan untuk membungkus bagian konten agar lebih terstruktur

5.Footer
Terletak di bagian paling bawah halaman. Berguna untuk:
Footer membuat halaman terlihat selesai dan profesional.

6. CSS Gradient Background
Walau bukan tag HTML, website Anda juga menggunakan CSS background gradient untuk menciptakan warna biru-ocean yang menyatu secara halus. Ini memberi suasana visual yang lebih hidup.

7. Bootstrap Utilities
Bootstrap membantu mempercepat desain tanpa menulis CSS panjang. Misalnya:
p-4 padding
text-center teks rata tengah
shadow-lg bayangan card
rounded-4 sudut membulat
