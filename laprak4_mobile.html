I. Pendahuluan

Pengembangan aplikasi mobile modern menuntut pembuatan antarmuka pengguna (User Interface) yang tidak hanya interaktif dan responsif, tetapi juga mampu mengelola navigasi antar halaman serta pengiriman data antar komponen (passing data) secara terstruktur. Framework Flutter, yang dikembangkan oleh Google menggunakan bahasa pemrograman Dart, menyediakan mekanisme navigasi berbasis Navigator untuk berpindah halaman serta pengelolaan formulir untuk pencatatan data.

Praktikum ini berfokus pada materi navigasi layar lanjutan dan pengelolaan formulir interaktif pada aplikasi Expense Tracker. Konsep dan teknologi utama yang diterapkan meliputi penggunaan StatelessWidget dan StatefulWidget, implementasi navigasi Navigator.push() dan Navigator.pop(), pengiriman data antar layar (Passing Data), penggunaan Form dan TextFormField, pemanfaatan TextEditingController untuk menangkap nilai input, validasi input menggunakan GlobalKey<FormState>, pemanggilan komponen interaktif showDatePicker untuk memilih tanggal, serta menampilkan umpan balik kepada pengguna menggunakan SnackBar.

Hubungan materi ini dengan pemrograman Dart/Flutter terletak pada penerapan struktur widget yang modular, di mana halaman utama (DashboardScreen) memuat ringkasan saldo dan daftar transaksi, halaman form (AddTransactionScreen) menangani penambahan data baru, dan halaman detail (TransactionDetailScreen) menampilkan informasi lengkap dari suatu transaksi yang dipilih. Pemanggilan metode setState() digunakan untuk memperbarui status tampilan, dan manajemen memori dilakukan melalui metode dispose() pada controller.

Materi ini sangat penting bagi mahasiswa Informatika karena pemahaman mengenai navigasi antar layar dan aliran data (data flow) merupakan fondasi utama dalam membangun aplikasi mobile multi-halaman yang kompleks dan dinamis.

II. Tujuan Praktikum

1

Memahami konsep dasar navigasi antar layar di Flutter menggunakan Navigator.push() dan Navigator.pop().

2

Mampu menerapkan pengiriman data (passing data) dari satu layar ke layar lainnya melalui konstruktor widget.

3

Memahami struktur dan implementasi formulir interaktif di Flutter menggunakan widget Form dan TextFormField.

4

Menerapkan TextEditingController untuk mengelola, membaca, dan mereset nilai masukan teks.

5

Menggunakan GlobalKey<FormState> untuk melakukan validasi masukan formulir sebelum data diproses.

6

Mengintegrasikan fungsi pemilih tanggal asynchronous (showDatePicker) dan memformat string tanggal secara manual.

7

Menerapkan ScaffoldMessenger dan SnackBar untuk memberikan konfirmasi visual saat data transaksi disimpan.

III. Langkah Praktikum

Berikut adalah tahapan implementasi praktikum navigasi lanjutan dan pengelolaan formulir pada aplikasi Expense Tracker:

Langkah 1 — Konfigurasi Utama Aplikasi dan Inisialisasi Tema (main.dart)

Nama/Judul Langkah: Konfigurasi Root App dan Halaman Utama Dashboard

Kode Program (main.dart)
import 'package:flutter/material.dart'; import 'dashboard_screen.dart'; void main() { runApp(const MyApp()); } class MyApp extends StatelessWidget { const MyApp({super.key}); @override Widget build(BuildContext context) { return MaterialApp( debugShowCheckedModeBanner: false, title: 'Expense Tracker - Modul 4', theme: ThemeData( primarySwatch: Colors.red, ), home: const DashboardScreen(), // Halaman pertama yang dimuat ); } }

Penjelasan Kode:

  • import 'package:flutter/material.dart';: Mengimpor pustaka Material Design untuk komponen UI Flutter.
  • import 'dashboard_screen.dart';: Mengimpor berkas layar utama DashboardScreen.
  • void main() => runApp(const MyApp());: Titik masuk utama aplikasi yang menjalankan widget MyApp.
  • class MyApp extends StatelessWidget: Widget utama aplikasi yang bersifat statis.
  • MaterialApp: Widget konfigurasi utama yang mengatur tema warna (primarySwatch: Colors.red) dan halaman awal (home).
  • home: const DashboardScreen(): Menetapkan DashboardScreen sebagai tampilan pertama yang dibuka saat aplikasi dijalankan.
Langkah 2 — Implementasi Halaman Dashboard dan Navigasi Pushing (dashboard_screen.dart)

Nama/Judul Langkah: Pembuatan Dashboard, Kartu Saldo, Daftar Transaksi, dan Tombol Navigasi

Kode Program (dashboard_screen.dart)
import 'package:flutter/material.dart'; import 'add_transaction_screen.dart'; import 'transaction_detail_screen.dart'; class DashboardScreen extends StatelessWidget { const DashboardScreen({super.key}); @override Widget build(BuildContext context) { return Scaffold( appBar: AppBar( title: const Text('Dashboard Keuangan'), backgroundColor: Colors.red, foregroundColor: Colors.white, ), floatingActionButton: FloatingActionButton( backgroundColor: Colors.red, foregroundColor: Colors.white, child: const Icon(Icons.add), onPressed: () { Navigator.push( context, MaterialPageRoute( builder: (context) => const AddTransactionScreen(), ), ); }, ), body: SingleChildScrollView( padding: const EdgeInsets.all(16.0), child: Column( crossAxisAlignment: CrossAxisAlignment.start, children: [ const Text( 'Halo, Zahran', style: TextStyle(fontSize: 20, fontWeight: FontWeight.bold), ), const SizedBox(height: 20), _buildBalanceCard(), const SizedBox(height: 20), const Text( 'Transaksi Terakhir', style: TextStyle(fontSize: 18, fontWeight: FontWeight.bold), ), const SizedBox(height: 12), _buildTransactionList(context), ], ), ), ); } // ... (kode fungsi pembantu _buildBalanceCard dan _buildTransactionList) }

Penjelasan Kode:

  • FloatingActionButton: Tombol aksi mengambang dengan ikon tambah (Icons.add) yang diletakkan di sudut layar.
  • Navigator.push(...): Berfungsi untuk berpindah dari layar DashboardScreen menuju layar AddTransactionScreen dengan menumpuk halaman baru di atas tumpukan navigasi (navigation stack).
  • SingleChildScrollView: Membungkus konten agar dapat digulir secara vertikal guna mencegah masalah overflow.
  • _buildBalanceCard(): Fungsi pembantu (helper method) untuk merender kartu informasi saldo utama dengan sudut melengkung.
  • _buildTransactionList(context): Menampilkan daftar transaksi berbentuk kartu (Card) yang berisi komponen ListTile untuk setiap item transaksi, serta mendukung navigasi passing data ke TransactionDetailScreen saat item ditekan.

Langkah 3 — Navigasi dan Pengiriman Data ke Layar Detail (transaction_detail_screen.dart)

Nama/Judul Langkah: Implementasi Halaman Detail Transaksi dan Konstruktor Berparameter

Kode Program (transaction_detail_screen.dart)
import 'package:flutter/material.dart'; class TransactionDetailScreen extends StatelessWidget { final String title; final String amount; final String category; final String date; const TransactionDetailScreen({ super.key, required this.title, required this.amount, required this.category, required this.date, }); @override Widget build(BuildContext context) { return Scaffold( appBar: AppBar( title: const Text("Detail Transaksi"), backgroundColor: Colors.red, foregroundColor: Colors.white, ), body: Padding( padding: const EdgeInsets.all(24.0), child: Column( crossAxisAlignment: CrossAxisAlignment.center, children: [ const Icon(Icons.receipt_long, size: 80, color: Colors.redAccent), const SizedBox(height: 24), Text(title, style: const TextStyle(fontSize: 24, fontWeight: FontWeight.bold)), const SizedBox(height: 8), Text(amount, style: const TextStyle(fontSize: 32, fontWeight: FontWeight.bold, color: Colors.red)), const Divider(height: 40, thickness: 2), _buildDetailRow('Kategori', category), const SizedBox(height: 16), _buildDetailRow('Tanggal', date), const SizedBox(height: 16), _buildDetailRow('Status', 'Berhasil'), ], ), ), ); } Widget _buildDetailRow(String label, String value) { return Row( mainAxisAlignment: MainAxisAlignment.spaceBetween, children: [ Text(label, style: const TextStyle(fontSize: 16, color: Colors.grey)), Text(value, style: const TextStyle(fontSize: 16, fontWeight: FontWeight.bold)), ], ); } }

Penjelasan Kode:

  • final String title, amount, category, date;: Variabel penampung data yang bersifat final karena widget ini berjenis StatelessWidget.
  • Constructor required this.title, ...: Mewajibkan pengiriman parameter data saat widget dipanggil dari layar lain.
  • _buildDetailRow(): Widget pembantu untuk menyusun baris informasi detail secara sejajar menggunakan Row dan MainAxisAlignment.spaceBetween.

Langkah 4 — Pengelolaan Form, Validasi, dan Pemilih Tanggal (add_transaction_screen.dart)

Nama/Judul Langkah: Implementasi Form Input, Date Picker, Validasi, dan Navigasi Pop

Kode Program (add_transaction_screen.dart)
import 'package:flutter/material.dart'; class AddTransactionScreen extends StatefulWidget { const AddTransactionScreen({super.key}); @override State<AddTransactionScreen> createState() => _AddTransactionScreenState(); } class _AddTransactionScreenState extends State<AddTransactionScreen> { final _formKey = GlobalKey<FormState>(); final _titleController = TextEditingController(); final _amountController = TextEditingController(); final _dateController = TextEditingController(); @override void dispose() { _titleController.dispose(); _amountController.dispose(); _dateController.dispose(); super.dispose(); } Future<void> _selectDate() async { final DateTime? pickedDate = await showDatePicker( context: context, initialDate: DateTime.now(), firstDate: DateTime(2020), lastDate: DateTime(2030), ); if (pickedDate != null) { setState(() { _dateController.text = '${pickedDate.day.toString().padLeft(2, '0')}/' '${pickedDate.month.toString().padLeft(2, '0')}/' '${pickedDate.year}'; }); } } @override Widget build(BuildContext context) { return Scaffold( appBar: AppBar( title: const Text("Catat Transaksi"), backgroundColor: Colors.red, foregroundColor: Colors.white, ), body: Padding( padding: const EdgeInsets.all(16.0), child: Form( key: _formKey, child: Column( crossAxisAlignment: CrossAxisAlignment.stretch, children: [ TextFormField( controller: _titleController, decoration: const InputDecoration( labelText: "Judul", border: OutlineInputBorder(), ), validator: (value) => value!.isEmpty ? "Tidak boleh kosong" : null, ), const SizedBox(height: 16), TextFormField( controller: _amountController, keyboardType: TextInputType.number, decoration: const InputDecoration( labelText: "Nominal", border: OutlineInputBorder(), ), validator: (value) => value!.isEmpty ? "Tidak boleh kosong" : null, ), const SizedBox(height: 16), TextFormField( controller: _dateController, readOnly: true, decoration: InputDecoration( labelText: "Tanggal Transaksi", hintText: "DD/MM/YYYY", border: const OutlineInputBorder(), suffixIcon: IconButton( icon: const Icon(Icons.calendar_today), onPressed: _selectDate, ), ), validator: (value) { if (value == null || value.isEmpty) { return "Tanggal transaksi wajib diisi"; } return null; }, ), const SizedBox(height: 32), ElevatedButton( style: ElevatedButton.styleFrom( backgroundColor: Colors.red, foregroundColor: Colors.white, padding: const EdgeInsets.symmetric(vertical: 16), ), onPressed: () { if (_formKey.currentState!.validate()) { ScaffoldMessenger.of(context).showSnackBar( const SnackBar( content: Text('Transaksi Berhasil Disimpan!'), backgroundColor: Colors.green, ), ); Navigator.pop(context); } }, child: const Text("Simpan", style: TextStyle(fontSize: 16)), ), ], ), ), ), ); } }

Penjelasan Kode:

  • _formKey = GlobalKey<FormState>(): Kunci unik untuk mengontrol status validasi seluruh elemen Form.
  • TextEditingController: Mengontrol dan mengambil nilai teks dari input judul, nominal, serta tanggal.
  • dispose(): Membersihkan memori controller saat widget dihancurkan untuk mencegah kebocoran memori (memory leak).
  • _selectDate(): Fungsi asynchronous yang menampilkan dialog showDatePicker untuk memilih tanggal, lalu memformatnya menjadi string "DD/MM/YYYY" menggunakan padLeft.
  • readOnly: true pada input tanggal: Mencegah pengguna mengetik secara bebas dan memaksa pemilihan melalui kalender.
  • _formKey.currentState!.validate(): Memeriksa apakah seluruh validasi pada kolom input bernilai benar.
  • Navigator.pop(context): Berfungsi untuk menutup halaman form dan kembali ke layar dashboard sebelumnya setelah data berhasil divalidasi dan disimpan.

IV. Kesimpulan

Hasil & Kesimpulan Praktikum
  • Berdasarkan seluruh rangkaian kegiatan praktikum yang telah dilakukan, dapat disimpulkan bahwa:
  • Navigasi antar layar pada Flutter berhasil diimplementasikan menggunakan Navigator.push() untuk membuka halaman baru dan Navigator.pop() untuk kembali ke halaman sebelumnya.
  • Pengiriman data antar layar (Passing Data) dapat dilakukan secara efektif melalui konstruktor widget dengan memanfaatkan parameter bertipe required.
  • Pembuatan formulir interaktif menggunakan kombinasi widget Form, TextFormField, dan TextEditingController memudahkan proses pengelolaan serta pengambilan data masukan pengguna.
  • Validasi data berhasil diterapkan menggunakan GlobalKey<FormState> untuk memastikan integritas data sebelum diproses lebih lanjut.
  • Fitur pemilih tanggal interaktif (showDatePicker) dan pemformatan string manual memberikan kemudahan serta fleksibilitas dalam pemilihan tanggal transaksi.
  • Kombinasi pengelolaan state, navigasi, dan validasi form menghasilkan aplikasi pencatat keuangan (Expense Tracker) multi-halaman yang responsif, terstruktur, dan fungsional.
